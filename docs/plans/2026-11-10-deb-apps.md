# 第三方 .deb 应用 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**前置：** `docs/plans/2026-11-10-exam-quiet.md` 已完成（本计划用它的 `quiet` 模块与 `STOP_UNITS`）。

**Goal:** IT 在 `[config.apps.deb.<id>]` 写名字、.deb 链接、是否锁定模式，设备自己下载、用 Ubuntu 源补齐依赖、做成 sysext 合并，
在普通会话的 Dock 或登录界面的锁定会话里可用。

**Architecture:** 照 Chrome：一个独立的一次性单元 `mastersos-deb-apps.service` 跑 `mastersos-agent deb-apps`（下载、apt 解析、组装、
合并），由定时器与常驻 agent（新包到达时 `systemctl start --no-block`）触发；常驻 agent 的 `DebAppsStatus` 任务只读结果并回报，
kiosk 与 desktop 步骤读它写下的公开状态文件。下载与扩展互换的代码从 `chrome_sysext.rs` 抽到共用模块 `sysext/`。

**Tech Stack:** Rust（tokio、reqwest、serde、nix），apt/dpkg-deb/gpgv，systemd-sysext，bash 测试。

**Spec:** `docs/specs/2026-11-10-deb-apps-design.md`

## Global Constraints

- 代码注释、错误、输出英文；提交信息中文；路径英文。
- id 规则同锁定应用（`^[a-z][a-z0-9-]{0,23}$`）；`kiosk = true` 的 id 与 `apps.kiosk` 共用名字空间，两者合计至多 `MAX_KIOSK_APPS` = 32。
- `url` 必须 `https://`，≤ 2048 字节；`sha256` 64 个小写十六进制；`packages` ≤ 32 个合法 Debian 包名；`.deb` ≤ 2 GiB。
- `ubuntu_mirror`：`http://` 或 `https://`，≤ 2048 字节；suite 用镜像的代号、`-updates`、`-security`。
- 扩展目录：`/var/lib/extensions/app-<id>`（主包）与 `/var/lib/extensions/app-deps`（共享依赖）；工作目录 `/var/lib/mastersos/deb-apps/`（0700）；
  公开状态 `/var/lib/mastersos-public/deb-apps.json`（0644，kiosk 与 desktop 步骤读）。
- 我们写的 `.desktop`：`usr/share/applications/mastersos-app-<id>.desktop`。
- `extension-release`：`ID=ubuntu`、`SYSEXT_LEVEL=<镜像 IMAGE_VERSION>`、`SYSEXT_SCOPE=system`。
- 全局合并锁 `/run/mastersos/sysext.lock`（flock），Chrome 与 .deb 应用共用。
- manifest feature `deb_apps`（`FEATURE_DEB_APPS`）。
- 不跑任何包的安装脚本；不升级/降级/删除镜像里的包；不盖镜像 `/usr` 或根分区 `/opt` 已有的文件；去 setuid/setgid。
- 静默中（`quiet` 模块）不开始；`mastersos-deb-apps.service` 加进 `quiet::STOP_UNITS` 并带同样的 `ExecCondition=`。
- 验证：`cd core && cargo fmt --check && cargo clippy --workspace --all-targets -- -D warnings && cargo test --workspace`；
  `bash image/tests/check-tree.sh`；shell 与 apt 测试在 `ubuntu:24.04` amd64 容器；提交前 `python3 -I tools/check-private.py`。

## Review Focus

1. 两个应用的依赖重叠：一起解析，`app-deps` 里每个包只有一份。
2. 依赖要求比镜像新的库（apt 的方案里有升级、降级或删除）：判失败，`deb:<id>` 说出包名与两个版本，不组装。
3. 镜像升级后（`SYSEXT_LEVEL` 变了）断网：用缓存离线重建成功，应用恢复。
4. 主包里有指向扩展外的绝对符号链接、`..` 路径或设备文件：拒绝，不跟随。
5. 设置里删掉一个正在使用的应用：推迟卸载，回报"等待应用关闭"，关闭后卸干净（含 `kiosk-<id>` 账号）。
